# 3-minute demo script

Use a staging project with the pilot seed loaded. Every record on screen is real
saved data, labelled `[Pilot]`. Never present sample rows as genuine works.

**0:00 — Hook.** "In South Chennai a road gets resurfaced, then dug up weeks
later for a cable. CivicSync stops that." Open the deployed dashboard.

**0:20 — Citizen, no login.** Search a road, open a `[Pilot]` project. Show
purpose, department, contractor, timeline, progress bar, and the live weather
delay-risk card.

**0:50 — My area.** Pick Adyar, set a radius, show upcoming works, click **Add
to calendar (.ics)** and open the downloaded event.

**1:15 — Dig-Once (the star).** Open Dig-Once. Show the Adyar
**repeat-dig** alert: a resurfacing and a fibre trench 80 days apart on the same
stretch. As an approved official, record a decision — "combine into one dig
window the week of …". Reload; the decision is public.

**1:55 — Close the loop.** As a citizen, **Report an issue → digging not on the
register**, drop a pin, add a photo, submit. Switch to an official's **Reports
inbox**, respond. Back as the citizen, **My reports** shows the response.

**2:25 — Scoreboard.** Show per-department on-time %, average delay and response
rate — accountability from the same data.

**2:45 — Close.** "Transparency, coordination and accountability on one open
stack — Supabase, React and open data — ready for one ward today." Show the live
URL and the repo commit.

**If something fails live:** show the real error and say what's missing. A
recording can be redone; a faked persistence claim cannot.
